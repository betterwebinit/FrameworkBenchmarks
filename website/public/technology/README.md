# Technology artwork

Locally served technology artwork from [Devicon v2.17.0](https://github.com/devicons/devicon/tree/v2.17.0) (MIT), [Simple Icons 15.0.0](https://github.com/simple-icons/simple-icons/tree/15.0.0) (CC0), and the frameworks' own websites and repositories. Original assets are unmodified. See `sources.json` for the collection asset URLs and adjacent license files, and `framework-coverage.json` for the project artwork sources, checksums, and research coverage. Brand names and logos remain the property of their respective owners; third-party project assets retain their original terms.

`app/technology-model.ts` maintains separate aliases for frameworks, languages, databases, and operating systems. `app/framework-artwork.ts` includes verified project assets and unambiguous implementation aliases from benchmark metadata. Snapshot framework metadata takes precedence over display aliases. Unknown technologies use a neutral UI symbol, never another project's logo. Labels retain the spelling supplied by the benchmark. New assets must have a verified source, a local image file, and a source entry here.

All 407 catalog entries were reviewed on 2026-09-28. Research used the benchmark READMEs and dependency manifests, official homepages, linked project repositories, README images, and repository logo files. Unavailable artwork is recorded as `no_verified_image`; this means no suitable image was verified during this review, not that no logo exists. Badges, graphs, sponsor logos, generic documentation-service icons, and unrelated identities were excluded during visual review. Some entries are platform or standard-library implementations without an independent visual identity.
